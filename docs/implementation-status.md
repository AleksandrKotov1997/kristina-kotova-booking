## Текущий законченный блок

Responsive mobile: общий Header показывает меню на узких экранах. Навигация
поддерживает активный маршрут, закрытие по Escape, возврат фокуса и переходы
между страницами. При возвращении на desktop открытое меню закрывается.
Отступы контейнеров и секций задаются общими токенами; адаптивные стили
остаются в CSS Modules соответствующих компонентов.

Главная, /services, /works и /about перестраиваются под телефон и планшет.
Каталог, галерея и её состояние загрузки, блок мастера, контакты и footer
адаптированы. Запись сохраняет три шага: календарь и слоты располагаются
вертикально, поля имеют читаемый размер, кнопки доступны для касания.
При смене шага фокус и прокрутка переходят к заголовку нового шага.
Возврат назад сохраняет контакты и выбранные дату/время.

В кабинете на телефонах список представлен карточками с клиентом, телефоном,
услугой, стоимостью, датой, интервалом и статусом. Таблица и карточки используют
один запрос, одну пагинацию и существующие действия смены статуса. Фильтры,
обзор, статистика, вход и окна подтверждения также адаптированы.

Проверено: 130 тестов, lint, typecheck, production-сборка и Docker.
Все семь страниц проверены на ширинах 320, 390, 768, 1024 и 1440 пикселей;
Header также на границе 1100. Горизонтального переполнения страницы нет.
В браузере проверены меню и клавиатура, просмотр фото, календарь, валидация,
возврат между шагами, отправка настоящей тестовой заявки и действия мастера
из карточек, включая подтверждение, отмену и завершение в Docker.
Четыре созданные тестовые заявки удалены по точным ID после проверки.
Закрытые API проверены без сессии. Локальные значения env отсутствуют в Git,
истории, клиентской сборке и файловой системе Docker-образа.

Следующий шаг по ТЗ — production-контент и публикация. Для него нужны
реальные фото, контакты и подтверждённый прайс. ТЗ целиком ещё не завершено.
blocked_slots предусмотрены и защищают время; отдельный UI ручных блокировок
остаётся допустимым будущим шагом по ТЗ.

### Auth

Supabase Auth: email/пароль, HttpOnly cookies, обновление сессии и выход.
Закрытые страницы и API независимо проверяют getUser() и private.studio_owner.
Разрешён один мастер; роль не берётся из cookie с ID или metadata. Демовход
удалён. Перенос аккаунта Кристине описан в README и не требует изменения env.

### Docker

Production-запуск добавлен отдельным этапом: localhost:3001, существующий
облачный Supabase, Node.js 24.21.0 LTS и pnpm 10.33.0. Многоэтапная сборка
использует frozen lockfile и standalone; сервер работает без root,
с init и healthcheck. Обычный pnpm dev/build/start сохраняет стандартный
режим Next.js. Инструкция запуска и остановки — в README.

.env.local подключается только при запуске; все файлы окружения исключены
из контекста сборки. Локальные ключи проверяются в Git и слоях образа,
в публичные исходники и образ не включаются. Публикация Vercel/Supabase остаётся
этапом production. Для .dockerignore закреплён текстовый режим VS Code.

### Booking

Запись завершена для desktop: услуга → дата и время → контакты → заявка.
Расписание — Астана, ежедневно 10:00–20:00. Шаг начала 30 минут, окно записи
90 дней; длительность берётся из активной услуги. Календарь и слоты доступны
с клавиатуры; прошлые/занятые интервалы недоступны. База защищает заявки и
ручные блокировки от пересечений, отмена освобождает время. Публичное чтение
имён/телефонов закрыто, повтор после потери ответа сохраняет UUID.
