## Текущий законченный блок

Docker-запуск добавлен отдельным шагом по запросу пользователя.
Compose запускает production-сервер Next.js на localhost:3001 с существующим
облачным Supabase. Dockerfile использует Node.js 24.21.0 LTS, pnpm 10.33.0,
frozen lockfile и многоэтапную standalone-сборку. Сервер работает от пользователя
node; предусмотрены init, healthcheck и корректное завершение запросов.

.env.local подключается только при запуске и не изменялся. Все .env\* исключены
из контекста сборки, Dockerfile копирует исходники явно. Значения локальных
ключей проверены в истории Git и всех слоях образа: совпадений нет.
Обычные pnpm dev/build/start сохраняют стандартный режим Next.js;
production-размещение Vercel/Supabase из ТЗ остаётся запланированным.
Инструкция запуска, выбора порта и остановки находится в README.

Проверено: сборка образа, healthy-контейнер, пользователь без root,
каталог/расписание/календарь из Supabase и реальная запись через API контейнера.
Параллельные пересекающиеся заявки дают 201/409; повтор возвращает прежнюю
заявку, pending занимает время. Тестовые записи удалены.
Также прошли lint, typecheck, обычная production-сборка и pnpm start.
Остановка, повторный запуск, смена порта и отдача public-ресурсов проверены.
Для .dockerignore закреплён текстовый режим VS Code, чтобы форматирование
не меняло правила исключения файлов.

### Последний продуктовый этап

Booking завершён для desktop: услуга → дата и время → контакты → заявка.
Расписание — Астана, ежедневно 10:00–20:00. Шаг начала 30 минут, окно записи
90 дней; длительность берётся из активной услуги. Календарь и слоты доступны
с клавиатуры; прошлые/занятые интервалы недоступны. База защищает заявки и
ручные блокировки от пересечений, отмена освобождает время. Публичное чтение
имён/телефонов закрыто, повтор после потери ответа сохраняет UUID.

Следующие продуктовые этапы — Supabase Auth мастера и закрытый кабинет
со списком заявок и обработкой статусов. Они пока не реализованы; ТЗ целиком
не завершено. UI ручных блокировок относится к Admin, сама сущность уже есть.
