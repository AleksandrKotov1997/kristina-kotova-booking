Город — Астана, сайт остаётся русским, расписание — ежедневно 10:00–20:00.

пересчитан по официальному курсу НБРК на 10.10.2026, множитель 5.35.

зарегистрирована в истории; она переводит и каталог, и сохранённые цены записей.

с откатом; проверочная запись не сохранена.

По просьбе владельца выбраны фотографии из интернета с акцентом на ресницы
и брови. Восемь снимков галереи поступают из Supabase через существующий API;
Hero и блок о мастере используют локальные фотографии. Подписи сообщают,
что это иллюстрации. Собственные работы и портрет можно добавить позже;
владелец явно согласовал стоковые изображения для текущего выпуска.
Сведения «3 года», «10 лет в красоте», «500+» и «5★» сохранены по его подтверждению.
Публичные тексты и metadata уточнены для Астаны, форматирование — ru-KZ.

Проверки бизнес-логики: 130 тестов, lint, typecheck и production-сборка
в Docker прошли. Галерея и контакты проверены в браузере.
Владелец уточнил, что текущий выпуск — личный некоммерческий проект
для портфолио. Размещение — Vercel Hobby и Supabase Free, без платных услуг.
Vercel-проект создан на Hobby, доступ ограничен этим репозиторием,
SUPABASE_URL и SUPABASE_PUBLISHABLE_KEY сохранены как Sensitive
для Production/Preview. Framework — Next.js, Node — 24.x, платные
параллельные сборки отключены. vercel.json фиксирует регион fra1.
Сборка Vercel успешно завершена. Сайт: https://kristina-kotova-booking.vercel.app.
Production отслеживает main; изменения проходят через отдельные ветки и PR.

На опубликованном сайте проверены все публичные страницы, каталог из базы,
галерея и календарь. Тестовая заявка создалась с pending, отобразилась
в кабинете мастера, подтвердилась и отменилась; занятое время недоступно,
после отмены снова доступно. Тестовая запись удалена с разрешения владельца
по точному ID. Вход проверен через настоящую сессию владельца.
Гостевые запросы к закрытым API возвращают 401, страницы кабинета
перенаправляют на вход. Значения локального env не найдены в HTML,
публичных JavaScript-файлах, Git и образе Docker.

ТЗ MVP завершено в рамках договорённостей: стоковые иллюстрации
разрешены владельцем, текущий выпуск предназначен для портфолио.

## Завершённая мобильная адаптация

Header поддерживает меню, клавиатуру и управление фокусом. Общие токены
задают отступы; публичные страницы, услуги, галерея, календарь и форма записи
перестраиваются под телефон и планшет. В кабинете карточки и таблица используют
один запрос, общую пагинацию и существующие действия статусов.
Формы входа и контактов используют POST, поля не попадают в URL до гидратации.

Проверено на ширинах 320, 390, 768, 1024 и 1440: переполнения нет.
Меню, просмотр фото, запись, действия мастера и закрытые API проверены.
Четыре тестовые заявки предыдущего этапа удалены по точным ID.
На этапе контента уточнён приоритет стилей кнопки Ant Design в Header,
чтобы она скрывалась на desktop независимо от порядка подключения CSS.

blocked_slots предусмотрены и защищают время; отдельный UI ручных блокировок
остаётся допустимым будущим шагом по ТЗ.

### Auth

Supabase Auth: email/пароль, HttpOnly cookies, обновление сессии и выход.
Закрытые страницы и API независимо проверяют getUser() и private.studio_owner.
Разрешён один мастер; роль не берётся из cookie с ID или metadata. Демовход
удалён. Перенос аккаунта Кристине описан в README и не требует изменения env.

### Docker

Production-запуск добавлен отдельным этапом: localhost:3001, существующий
облачный Supabase, Node.js 24.21.0 LTS и pnpm 10.33.0. Многоэтапная сборка
использует frozen lockfile и standalone; сервер работает без root,
с init и healthcheck. Обычный pnpm dev/build/start сохраняет стандартный
режим Next.js. Инструкция запуска и остановки — в README.

.env.local подключается только при запуске; все файлы окружения исключены
из контекста сборки. Локальные ключи проверяются в Git и слоях образа,
в публичные исходники и образ не включаются. Vercel использует тот же
облачный Supabase. Для .dockerignore закреплён текстовый режим VS Code.

### Booking

Запись завершена для desktop: услуга → дата и время → контакты → заявка.
Расписание — Астана, ежедневно 10:00–20:00. Шаг начала 30 минут, окно записи
90 дней; длительность берётся из активной услуги. Календарь и слоты доступны
с клавиатуры; прошлые/занятые интервалы недоступны. База защищает заявки и
ручные блокировки от пересечений, отмена освобождает время. Публичное чтение
имён/телефонов закрыто, повтор после потери ответа сохраняет UUID.
